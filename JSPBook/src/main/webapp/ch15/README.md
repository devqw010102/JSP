## DB

#### DB(데이터베이스)
<pre>
  데이터베이스는 여러 자료를 동시에 여러 사람이 공유하여 사용할 수 있도록 체계화한 데이터의 집합
</pre>

#### DBMS(데이터베이스 관리 시스템)
<pre>
  데이터베이스를 관리하는 소프트웨어, 다수의 사용자와 데이터베이스 사이에서 사용자의 요구에 따라 정보를 생성하는 역할
</pre>

#### SQL 문장
| SQL 문장 | 종류 |
| -------- | ---- |
| 데이터 정의 언어(DDL) | CREATE, ALTER, DROP, ... |
| 데이터 조작 언어(DML) | SELECT, INSERT, DELETE, UPDATE, ... |
| 데이터 제어 언어(DCL) | GRANT, REVOKE, COMMIT, ROLLBACK, ... |
